LLM 에이전트를 활용한 벌크 RNA-seq 발현차이 분석 자동화가 시도되고 있으나, 데이터의 통계적 가정을 검증하지 않고 특정 도구를 무조건 적용하는 문제가 있었다. 이로 인해 소규모 샘플이나 이상치가 존재하는 데이터에서 FDR이 상승하거나 검정력이 떨어지는 결과가 발생한다. 연구진은 분석 실행 전 데이터 진단을 통해 부적합한 도구를 걸러내는 통계 가정 인지형 워크플로우인 DE-Rigor-Agent를 제안한다.

## 무엇을 했나

- 입력 표준화, 도구 필터링, 도구 실행의 3단계로 구성된 벌크 RNA-seq DE 분석 에이전트 워크플로우를 구축했다.
- 6개 주요 DE 분석 방식을 대상으로 전문가 진단 기준을 적용해 부적합 도구의 배제 사유를 명시하고 적합 도구만 실행하도록 설계했다.
- 샘플 수가 적거나 이상치 및 치우친 배치 효과가 존재하는 14가지 난이도 조건의 140개 시뮬레이션 데이터셋으로 평가를 진행했다.
- 범용 LLM이 무조건 DESeq2나 edgeR을 선택한 것과 달리, 데이터 부적합 요소를 정확히 감지하여 오탐률 증가를 방지함을 확인했다.

## 왜 눈여겨볼 만한가

데이터의 수치적 특성과 통계적 가정을 고려하지 않고 DESeq2나 edgeR을 관습적으로 적용하던 기존 파이프라인의 허점을 파악한 연구다. Zero inflation이나 정규화 여부 등 데이터 조건에 따라 분석 도구를 자동 선별하므로 DE 분석의 엄밀성을 높이는 데 유용해 보인다. 다만 시뮬레이션 데이터 중심의 검증이므로 복잡한 임상 공변량이 얽힌 실제 데이터에서도 필터링 로직이 유효할지는 추가 검증이 필요하다.
