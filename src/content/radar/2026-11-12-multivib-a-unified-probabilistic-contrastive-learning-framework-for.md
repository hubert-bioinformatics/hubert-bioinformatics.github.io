서로 다른 연구 환경이나 오믹스 모달리티, 종 간 단일세포 데이터를 통합할 때 노이즈로 인한 가짜 정렬이 쉽게 발생하는 한계가 있었다. multiVIB는 변분 정보 병목과 확률적 대조 학습을 결합해 수평·수직·모자이크 통합을 정교하게 수행한다.

## 무엇을 했나

- 변분 정보 병목(VIB)과 확률적 대조 학습 프레임워크를 기반으로 다중오믹스 노이즈를 제어하는 multiVIB 모델을 설계했다.
- 수평, 수직, 모자이크 형태의 단일세포 다중오믹스 벤치마크 데이터셋에서 과도한 보정 없이 통합 성능을 입증했다.
- BRAIN Initiative 아틀라스 데이터를 활용해 마우스 1차 운동 피질의 9개 분자 모달리티를 점진적으로 통합했다.
- 영장류 기저핵 전사체 데이터를 종 간 통합하여 보존된 세포 정체성과 종 특이적 분자 프로그램을 성공적으로 구분했다.

## 왜 눈여겨볼 만한가

기존 단일세포 통합 알고리즘에서 흔히 발생하는 과도한 데이터 보정과 가짜 정렬 문제를 확률적 접근법으로 개선한 점이 실무적으로 유용하다. 특히 이미 구축된 아틀라스에 새로운 모달리티나 데이터셋을 순차적으로 합치는 증분 통합이 가능해 대형 프로젝트에 적합하다. 다만 아틀라스급 대용량 데이터 처리 시 GPU 메모리 요구량과 모델 추론 속도는 직접 검증해 볼 필요가 있다.
